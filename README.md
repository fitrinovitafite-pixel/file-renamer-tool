# File Renamer Tool

A simple Python tool for automatically renaming files in a folder.

## Description

This beginner-friendly project reads files from a folder and automatically renames them using Python's `os` module.

The program adds `renamed_` to the beginning of each file name.

## Features

- Reads files from a folder
- Renames files automatically
- Adds a prefix to file names
- Displays the old and new file names

## Technologies

- Python
- OS module

## Learning Purpose

This project was created to practice:

- Importing modules
- Variables
- Lists
- `os.listdir()`
- `os.path.join()`
- `os.rename()`
- `for` loops
- String concatenation
- File and folder operations
- Indentation

## How to Use

1. Create a folder named `files`.
2. Put the files you want to rename inside the folder.
3. Run the Python program.
4. The program will add `renamed_` to each file name.

## Example

Before:

```text
Foto1.jpg
Foto2.jpg
Foto3.jpg

after :

renamed_Foto2.jpg
renamed_Foto3.jpg

example output
